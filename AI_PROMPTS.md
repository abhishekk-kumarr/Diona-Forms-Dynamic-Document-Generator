Identify their page structure, headers, footers, page numbers, tables, checkboxes, dynamic data fields, and visual layout. Build a solution using only HTML, CSS and JavaScript that recreates both documents in the browser."

## Prompt 2 — Dynamic behavior

## Prompt 3 — Print fidelity
"Use A4 print CSS, page breaks, headers/footers, tables, spacing, borders and typography to make the browser output resemble the supplied PDFs."

## Prompt 4 — Submission support
"Create a README explaining how to run the project, demonstrate dynamic behavior, disclose AI assistance, and provide guidance for the required two narrated videos."
